# ドキュメントレビュー

引数のドキュメント（例: `/review-docs docs/product-requirements.md`）を `doc-reviewer` サブエージェントでレビューする。

1. 指定されたファイルが存在しなければ、その旨を伝えて終了する
2. `doc-reviewer` サブエージェントにファイルパスを渡してレビューさせる
3. 結果をユーザーに伝える。指摘は重大度順に並べ、必須の指摘には対応するかどうかを尋ねる。ドキュメントの修正はユーザーの指示があるまで行わない
